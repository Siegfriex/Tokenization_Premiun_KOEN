## 2. 가장 중요한 O/X 정의

### O

아래 질문에 **"예, 이 분석이면 말이 된다"** 고 답할 수 있으면 O입니다.

> 이 한국어 문장을 형태소 단위로 쪼갠 결과와 붙은 품사가
> 한국어 문법상 납득할 만한가?

다른 분석 방법도 가능해 보여도, **지금 결과가 틀리지 않았다면 O** 입니다.

### X

다음 중 하나라도 있으면 X입니다.

- 형태소 경계가 명백히 잘못 잘렸다
- 품사가 명백히 틀렸다
- 원래 문장에 없는 형태가 나왔거나, 있는 형태가 사라졌다
- 조사인데 조사로 안 잡혔다 / 조사가 아닌데 조사로 잡혔다
- 어미·파생접사도 마찬가지
- 분석 결과가 문장의 의미를 왜곡한다
- **너무 애매해서 확신이 안 선다**

### 그리고 반드시 기억할 것

```
X ≠ 오류 확정
X ≠ 코드 버그 확정
X ≠ 해당 문장 제외
X = 다시 볼 가치가 있음
```

X는 **"여기 좀 봐 주세요" 플래그**입니다. 애매하면 망설이지 말고 X를 주십시오.

## 3. 실제로 무엇을 보는가 — 6가지

품사 약어는 이 6개 묶음만 기억하면 충분합니다.

| 묶음 | 태그 | 뜻 |
|---|---|---|
| 체언 | `NNG` `NNP` `NP` `NR` | 일반명사 / 고유명사 / 대명사 / 수사 |
| 용언 | `VV` `VA` `VX` `VCP` `VCN` | 동사 / 형용사 / 보조용언 / 이다 / 아니다 |
| **조사** | `J`로 시작 (`JKS` `JKO` `JKB` `JX` `JC` …) | 은/는/이/가/을/를/에/에서/도/만 … |
| **어미** | `E`로 시작 (`EF` `EC` `EP` `ETM` `ETN`) | 종결/연결/선어말/관형형/명사형 어미 |
| **파생접사** | `XSN` `XSV` `XSA` (+ `-I` `-R` 붙은 변이형) | 명사파생 / 동사파생 / 형용사파생 접미사 |
| 기타 | `MAG` `MM` `SF` `SP` `SL` `SN` `SH` | 부사 / 관형사 / 마침표 / 쉼표 / 외국어 / 숫자 / 한자 |

> `-I` / `-R` 이 붙은 태그(`VA-I`, `VV-R`, `XSA-I` …)는 **불규칙 활용 표시**입니다.
> `XSA-I`도 `XSA`와 같은 형용사파생 접사입니다. 이번 수정의 핵심이 바로 이 부분입니다.

---

### 3.1 형태소 경계

```
KO   : 학교에 갑니다
분석 : 학교/NNG 에/JKB 가/VV ᆸ니다/EF
```
→ **O**

```
KO   : 학교에 갑니다
분석 : 학교에/NNG 갑니다/VV
```
→ **X** (조사 `에`와 어미 `ᆸ니다`가 분리되지 않음)

---

### 3.2 품사 부착

```
KO   : 그는 빠르게 달렸다
분석 : 그/NP 는/JX 빠르/VA 게/EC 달리/VV 었/EP 다/EF
```
→ **O**

```
KO   : 그는 빠르게 달렸다
분석 : 그/NP 는/JX 빠르게/MAG 달렸다/NNG
```
→ **X** (`달렸다`가 명사로 붙음)

---

### 3.3 조사 (`J*`)

```
KO   : 회사에서 발표를 했다
분석 : 회사/NNG 에서/JKB 발표/NNG 를/JKO 하/VV 았/EP 다/EF
```
→ **O**

조사가 아닌 것이 `J*`로 붙었거나, 명백한 조사가 다른 품사로 붙었으면 X입니다.

---

### 3.4 어미 (`E*`)

```
KO   : 먹었습니다
분석 : 먹/VV 었/EP 습니다/EF
```
→ **O**

시제(`었`)·종결(`습니다`)·연결(`고`, `서`)·관형형(`는`, `ㄴ`)이 어미로 잡혀야 합니다.

---

### 3.5 파생접사 (`XSN` / `XSV` / `XSA`) — **이번에 특히 봐 주십시오**

```
KO   : 학생답게 행동한다
분석 : 학생/NNG 답/XSA-I 게/EC 행동/NNG 하/XSV ᆫ다/EF
```
→ **O** (`답`이 형용사파생 접사, `하`가 동사파생 접사)

```
KO   : 사랑스럽다
분석 : 사랑/NNG 스럽/XSA-I 다/EF
```
→ **O**

```
KO   : 공부하였습니다
분석 : 공부/NNG 하/XSV 였/EP 습니다/EF
```
→ **O**

`참고_메트릭` 시트의 `has_irregular_affix` 가 `True` 인 4개 행이 바로 이 수정으로 값이 바뀐 사례입니다. **이 4건은 특히 꼼꼼히 봐 주십시오.**

---

### 3.6 형태 복원

분석 결과의 `형태` 부분은 원형으로 복원됩니다. 원문 표기와 달라도 정상입니다.

```
KO   : 추워서
분석 : 춥/VA-I 어서/EC        →  O  (춥 → 추워 불규칙)

KO   : 걸어서
분석 : 걷/VV-I 어서/EC        →  O  (걷 → 걸어 불규칙)
```

원문에 없는 **엉뚱한 단어**가 나왔을 때만 X입니다.

## 4. 평가하지 않는 것

다음은 이번 audit의 대상이 **아닙니다.**

- tokenizer / BPE 경계와 맞는가 → **무관합니다**
- 영어 번역과 대응되는가 → 이번엔 영어를 보지 않습니다
- 다른 형태소 분석기라면 다르게 나눌 것 같다 → 그것만으로는 X가 아닙니다
- 고유명사가 사전에 없어 쪼개졌다 → analyzer 한계이며 그 자체로 X가 아닙니다
  (예: 낯선 회사명이 `NNG + NNG`로 쪼개진 것)
- 원문에 오타·띄어쓰기 오류가 있는데 analyzer가 최선을 다했다 → X가 아닙니다
- 문장이 비문이다 / 문체가 어색하다 → 무관합니다
- 더 세밀하게 쪼갤 수도 있었다 → 지금 결과가 틀리지 않으면 O입니다

핵심은 **번역 품질도 아니고 tokenizer도 아니고, 형태소 분석의 타당성 하나**입니다.

## 6. 애매할 때 — 여기가 제일 중요합니다

이건 **엄격한 언어학 시험이 아닙니다.**

```
이 분석대로 읽어도 문장의 구조가 말이 되는가?

  YES        → O
  NO / 애매  → X
```

### 사소한 차이는 O

```
KO   : 그는 어제 병원에 갔다
분석 : 그/NP 는/JX 어제/MAG 병원/NNG 에/JKB 가/VV 았/EP 다/EF
```
→ O. `어제`를 `MAG`(부사)로 볼지 `NNG`(명사)로 볼지는 분석기마다 갈립니다. 이 정도는 O입니다.

### 핵심이 무너지면 X

```
KO   : 그는 어제 병원에 갔다
분석 : 그는어제/NNP 병원에갔다/NNG
```
→ X. 조사도 어미도 잡히지 않았습니다.

## 7. 아주 짧은 문장

짧은 조각은 너무 엄격하게 보지 않습니다.

```
KO: 로그인      분석: 로그인/NNG              → O
KO: 예약 취소   분석: 예약/NNG 취소/NNG        → O
KO: 가능        분석: 가능/NNG                → O
```

문맥이 없어 판단이 안 되면 그냥 **X**로 두십시오. 억지로 결론 내지 마십시오.
이번 표본은 어절 1개짜리 문장도 포함하고 있습니다.

## 10. X는 그 다음 어떻게 되나

예를 들어 `O = 94, X = 6` 이면 그 6건만 2차로 다시 봅니다.
2차에서는 대략 이 정도만 구분하면 충분합니다.

```
A. 다시 보니 문제 없음
B. 경미한 분석 차이
C. 명백한 오분석
D. 반복되는 구조적 문제 의심
```

이 분류를 `.xlsx`에 적어 넣으실 필요는 없습니다. Claude-B가 X 목록을 받아 내부적으로 판정합니다.

## 11. 정말 위험한 X는 어떤 것인가

X 하나하나는 별로 중요하지 않습니다. **패턴이 위험합니다.**

- `technology`(특허 문서) 도메인에서만 X가 반복됨
- 파생접사가 붙은 문장에서만 반복적으로 X
- 특정 길이 구간(예: 아주 짧은 Q1)에서만 X가 몰림
- 문장부호·숫자·라틴문자가 섞인 문장에서만 X
- 같은 종류의 오분할이 여러 문장에서 반복

이런 것이 나오면 **분석 규칙 자체를 다시 봐야 합니다.**

반대로 100건 중 몇 건이 서로 무관한 이유로 애매한 것은 일반적인 corpus noise일 수 있습니다.

## 12. 한 장 요약

```
==========================================
KOEN 형태소 분석 검수 — O / X
==========================================

질문:
"이 한국어 문장의 형태소 분할과 품사가 타당한가?"

영어 번역은 보지 않는다.
tokenizer와도 무관하다.

O
- 형태소 경계가 납득 가능
- 품사가 납득 가능
- 조사 J* / 어미 E* / 파생접사 XS* 가 제자리
- 다른 분석도 가능해 보이지만 틀리진 않음
- 원형 복원(춥→춥, 걷→걷)은 정상
- 사전에 없는 고유명사가 쪼개진 것은 정상

X
- 명백한 오분할 (조사·어미가 안 떨어짐)
- 명백한 오품사
- 원문에 없는 형태가 등장
- 조사/어미/파생접사 오판정
- 의미가 왜곡됨
- 판단이 애매함

특히 볼 것:
  XSA-I / XSV / XSN 파생접사 (참고_메트릭의
  has_irregular_affix = True 인 4건)

기준치:
  형태소/어절 ≈ 2.2
  (조사+어미)/형태소 ≈ 0.34
  파생접사 ≈ 문장당 1개

중요:
  X = reject 아님
  X = 다시 볼 것
  표본의 40%는 의도적 극단값

애매하면 X.
오래 고민하지 말 것.
==========================================
```
